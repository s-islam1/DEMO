## Lab 12: From Excel Workbook to Stunning Report in Power BI Desktop

**What we’re doing:**
You’ll import a sample Excel “Financials” workbook into Power BI Desktop, apply basic data transformations, then build an executive-style report with five visuals (including a slicer) and light formatting.&#x20;

### Step-by-Step Instructions

1. **Get the Data**

   1. Launch Power BI Desktop.
   2. On the **Home** ribbon, click **Learn with sample data** → **Load sample data**.
   3. *Alternatively*, download the Excel file from the Microsoft link, then on **Home** click **Get Data** → **Excel**, browse to the workbook, and click **Open**.&#x20;

2. **Prepare the Data**

   1. In the **Navigator** preview, select **Transform Data**.
   2. In Power Query Editor:

      * Select **Units Sold**, Transform → Data Type → Whole Number (Replace current).
      * Select **Segment**, Transform → Format → UPPERCASE.
      * Rename **Month Name** column to **Month** by double-clicking.
      * Filter the **Product** column to remove “Montana.”
   3. Click **Close & Apply**.&#x20;

3. **Build Your Report**

   1. **Title**

      * Insert → Text box. Type “Executive Summary – Finance Report,” set font size 20 pt and **Bold**.
   2. **Visual 1: Profit by Date**

      * Drag **Profit** → canvas, then **Date** → same visual.
      * In X-axis, change from Date Hierarchy to Date.
      * Switch to **Line chart**.
   3. **Visual 2: Profit by Country/Region**

      * Drag **Country** → blank canvas (map).
      * Drag **Profit** into the map’s **Bubble size**.
   4. **Visual 3: Sales by Product & Segment**

      * Arrange the first two visuals side by side.
      * Drag **Sales**, **Product**, **Segment** → lower canvas (clustered column).
   5. **Visual 4: Year Slicer**

      * Drag **Date** (Financials table) → canvas → choose **Slicer**.
      * *Extra slicer:* Drag **Date** (Calendar table, if you created one via DAX extra credit) → canvas → **Slicer** → remove Quarter/Day so only Year & Month remain.&#x20;

4. **Extra Credit (optional)**

   * **New Measure**: Home → **New measure**, enter

     ```DAX
     Total Units Sold = SUM(Financials[Units Sold])
     ```
   * **New Table**: Home → **New table**, enter

     ```DAX
     Calendar = CALENDAR(DATE(2013,1,1), DATE(2014,12,31))
     ```
   * Create relationship: Model view → drag **Date** from Financials to **Date** in Calendar.&#x20;

5. **Format & Polish (optional)**

   * View → Theme → **Executive**.
   * For each visual: open **Format** pane → adjust titles (text & size), toggle Shadows, map styles, slicer “Select all” option, etc.
   * Insert → Shapes → Rectangle behind title and visuals → set fills, send to back, adjust text color.&#x20;

6. **Save & Publish**

   * File → **Save** (Ctrl + S).
   * To share: Home → **Publish**, choose workspace, then **Share** in Power BI Service.&#x20;

## Lab 13: From Dimensional Model to Stunning Report in Power BI Desktop

**What we’re doing:**
You’ll import an AdventureWorks star-schema Excel model, verify types, build relationships and hierarchies, hide key columns, optionally author a DAX measure, then create a Sales report with five visuals and formatting.&#x20;

### Step-by-Step Instructions

1. **Get the Data**

   1. Download the AdventureWorks Sales sample Excel workbook.
   2. In Power BI Desktop, Home → **Excel** → open the downloaded file.
   3. In **Navigator**, select all tables (not the `_data` sheets) → **Transform Data**.&#x20;

2. **Prepare the Data**

   1. In Power Query Editor, for each query:

      * Select columns → Transform → Detect Data Type (or manually set correct types on Home → Data Type).
   2. Close & Apply.&#x20;

3. **Model the Data**

   1. Switch to **Model** view.
   2. Create relationships: drag **DateKey** → **OrderDateKey**, **DateKey** → **DueDateKey**, **DateKey** → **ShipDateKey** (two will be inactive).
   3. Hide all key columns (those ending with “Key”): click the eye icon → **Hide in report view**.
   4. Create hierarchies (e.g. Country → State → City; Fiscal Year → Quarter → Month): right-click top level → **Create hierarchy** → add levels.
   5. Rename tables to remove underscores/spaces issues (in Properties pane).&#x20;

4. **Extra Credit: DAX Measure (optional)**

   1. Data view → select **Sales** table → Home → **New measure**.
   2. Enter:

      ```DAX
      Sales Amount by Due Date =
        CALCULATE(
          SUM(Sales[Sales Amount]),
          USERELATIONSHIP(Sales[DueDateKey],'Date'[DateKey])
        )
      ```
   3. Commit.&#x20;

5. **Build Your Report**

   1. **Title**: Insert → Text box “Executive Summary – Sales Report,” set size 20 pt, **Bold**, disable background.
   2. **Visual 1 – Sales Amount by Date**:

      * Drag **Sales Amount** → canvas → remove unwanted hierarchy levels on X-axis → change to **Area chart**.
      * Add the DAX measure (if created) to Y-axis and tweak line color.
   3. **Visual 2 – Order Quantity by Reseller Country/Region**:

      * Drag **Country-Region** (Reseller) → map; then **Order Quantity** → Bubble size.
   4. **Visual 3 – Sales Amount by Product Category & Reseller Business Type**:

      * Arrange visuals side by side.
      * Lower canvas: select **Sales Amount**, **Product Category**, **Business Type** → switch visual to **Matrix**, move Business Type to Columns, filter out “Not Applicable,” enable data bars.
   5. **Visual 4 – Fiscal Calendar Slicer**:

      * Drag **Fiscal** hierarchy (Date) → **Slicer** → remove Quarter/Date so only Year & Month remain.
   6. **Visual 5 – (if desired)**: additional slicer or other insight.&#x20;

6. **Format & Polish**

   * View → **Themes** → **Executive**.
   * For each visual: Format pane → adjust titles, text size 16 pt, Shadows On.
   * Insert shapes behind title and visuals → set fill/transparency → Send backward → adjust text color.&#x20;

7. **Save & Publish**

   * File → **Save**.
   * Home → **Publish** → choose workspace → **Share** in Power BI Service.&#x20;

Follow these steps in Power BI Desktop, and you’ll transform raw Excel data (whether flat or dimensional) into polished, interactive reports that answer your stakeholders’ top questions.
